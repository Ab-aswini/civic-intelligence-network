## 05 · The Math

### Signal Strength Algorithm

> How does a signal go from 0 to 89? Here's the exact breakdown.

```
SOURCE                    POINTS    CAP     HOW IT'S CALCULATED
─────────────────────     ──────    ────    ───────────────────────────────
Citizens (47 confirms)    +35       35      First 20 = 1.5 pts each
                                            Remaining 27 = 0.33 pts each
                                            (diminishing returns)

Primary Verifier          +28       48      base(18) × accuracy(0.94) × tier(1.6)
(Ramesh · Master · 94%)                     = 27.07 → rounded to 28

Supporting Verifier       +20       48      base(18) × accuracy(0.91) × tier(1.3)
(Sunita · Senior · 91%)                     = 21.29 → rounded to 20
                                            +INDEPENDENT BONUS (sealed view)

NGO Co-signature          +15       15      Institutional endorsement
(PRADAN Balangir)                           14 households = full 15 pts

Admin Authorization       +6        6       Final review + legal sign-off
──────────────────────────────────────────────────────────────────────────
TOTAL                     89/100            FILING THRESHOLD: 70/100 ✓
```

### Market Fairness Index

```
MFI = Violation Rate      × 0.40    →  How many commodities are above MRP
    + Avg Price Deviation  × 0.35    →  Average % markup across all commodities
    + Severity Index       × 0.15    →  Weighted by essential commodity ranking
    + Report Volume        × 0.10    →  Number of active signals this week

CURRENT BALANGIR MFI: 38/100 ── CRITICAL 🔴
```

### Partner Trust Tiers

| Tier | Symbol | Min Reports | Min Accuracy | Weight | What It Means |
|:---|:---:|:---:|:---:|:---:|:---|
| **Master** | `★` | 200+ | 93%+ | `×1.6` | Their word carries 60% more weight |
| **Senior** | `▲` | 50+ | 90%+ | `×1.3` | Proven track record |
| **NGO** | `■` | institutional | — | `×1.2` | Organizational credibility |
| **Active** | `●` | 10+ | 85%+ | `×1.0` | Baseline trusted partner |
| **New** | `○` | <10 | — | `×0.5` | Probationary — half weight |

> [!NOTE]
> **Why sealed verification matters:** When Sunita verified the LPG signal, she could NOT see Ramesh's notes. Two journalists arriving at the same conclusion independently is dramatically stronger evidence than two journalists reading each other's work. The system enforces this structurally.

## 12 · Security & Anonymity

> [!IMPORTANT]
> **The system _cannot_ identify who submitted a signal. This is not a policy — it's an architectural constraint.** There is no login system. No account system. No cookies. No IP logging. Signals contain only: commodity, area, price, and an optional text note. Even under court order, there is nothing to hand over.

| Layer | Mechanism |
|:---|:---|
| **Identity** | No login. No account. No session. No cookies. No fingerprinting. |
| **Data** | Signals = commodity + area + price. No PII fields exist. |
| **Verification** | Sealed view: journalists can't see each other's notes |
| **Storage** | Blockchain: immutable, append-only, tamper = chain break |
| **Accountability** | Authority response rates: permanent, public, no delete button |
| **Code** | 100% open source. No hidden endpoints. No analytics. |
| **Language** | Odia support so literacy in English isn't a barrier |
